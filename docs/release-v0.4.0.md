Solbrand Demo 简体中文汉化补丁 0.4.0 / 汉化助手 1.4.0

## 修复 Steam 更新后汉化不可用

支持 Steam Demo **Build 26869508**，同时兼容 **Build 26815196**。助手会按资源指纹选择对应补丁，保留版本与资源校验，不会用旧剧情覆盖新版剧情。

普通玩家下载 **Solbrand-ZH-Assistant-v1.4.0.exe** 直接运行，或下载同名 Windows ZIP 包解压使用；无需下载 GitHub 的 Source code。

## 已安装旧补丁的玩家

1. 退出游戏，等待 Steam 更新完成。
2. 打开本版助手，确认游戏位置。出现“Steam 已更新 · 需要重新汉化”时，点击“更新至 0.4.0”。
3. 等待完成，从 Steam 启动游戏。

不要删除 `.solbrand-zh`，也不需要先用旧助手回退。新助手会把旧版原版备份与记录完整移入 `.solbrand-zh/archive/`，再单独备份新版原版。此后“回退原版”恢复的是当前新版，不会降回旧 Build。原版与汉化存档均保留。

未安装补丁的原版玩家点击“一键安装汉化”即可。仍停留在旧 Build 的玩家也可直接更新补丁。

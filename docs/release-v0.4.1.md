Solbrand Demo 汉化补丁 0.4.1 / 助手 1.4.1

本版修复玩家截图反馈的漏译和手册缺字。支持 Steam Build 26869508 与 26815196。

## 下载和更新

下载 `Solbrand-ZH-Assistant-v1.4.1.exe` 直接运行，或下载 Windows ZIP 解压使用。退出游戏，确认目录后点击“更新至 0.4.1”。已有补丁可直接升级，不必先回退，也不要删除 `.solbrand-zh`。原版备份与存档保留。

## 本版修复

- 暂停菜单创建的文字仍会进行翻译；补充字母间有空格的 `CONTINUE` 显示适配。
- 任务日志使用逐段追加方式绘制时也能翻译，包括“船长让我沿着前任留下的供气管线检查，确认它是否运作正常”。日志刷新或追加后仍可翻译。
- 期刊手册完整显示“修复并研究被太阳灼损的期刊，获取关键信息，寻找答案”，不再被原有遮蔽效果隐藏。
- 期刊图示下补充 ARKIV（档案）与 PERIOD（期刊）的中文对照。原视频中的贴图文字保留。
- 手册 Description、Notice 等场景字段也在构建时替换；仅移除这条操作说明和其占位提示的遮蔽标签，剧情与解谜材料的遮蔽保持原样。

## 验证

Godot 定向回归通过：暂停状态、字母间距、逐段追加的任务日志、再次追加、清空重绘、期刊完整说明。字体、FontVariation、BBCode、Label3D、按钮和 Arkiv 材料译注的既有回归也通过。真实游戏资源副本已验证从 0.4.0 升级至 0.4.1，并精确回退原版；没有修改实际游戏安装或存档。

## 使用

1. 在 Steam 安装 Solbrand Demo，支持 Steam Build **26815196**，退出游戏。
2. 打开助手，确认游戏路径，点击“一键安装汉化”或“更新至 0.3.0”。
3. 等待完成，点击“在 Steam 中启动游戏”。
4. 恢复原版时，退出游戏后点击“回退原版”。

助手会自动备份原版，备份位于游戏目录 `.solbrand-zh`，请在需要回退时保留。原版与汉化使用独立存档，更新和回退不会删除两套存档。

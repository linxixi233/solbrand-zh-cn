Solbrand 一键 GitHub 上传

双击“一键上传到GitHub.cmd”。

首次运行：
1. 检查 GitHub 登录；如果尚未登录，按 Git 凭据管理器显示的设备码完成浏览器授权。
2. 自动构建汉化助手，并运行安装/回退等检查。
3. 自动在该账号下创建公开仓库 solbrand-zh-cn。
4. 提交并上传源码，发布包含 EXE、ZIP、SHA256SUMS.txt 的 Release。

以后有修改时，再次双击同一个文件即可。
没有改动时会提示无需重复上传。相同补丁版本有新提交时，Release 会使用 -r2、-r3 等新标签。

脚本使用 Git for Windows 自带的 Git 凭据管理器，凭据保存于其安全存储；
不会把令牌写进脚本、Git 仓库或本地配置文件。
本地 .github-upload.local.json 只保存仓库、游戏目录与上次上传状态，已加入忽略列表。
游戏原版、存档、提取目录与本机配置不上传；构建时只读取原版游戏资源。

默认会构建并发布 Release，需要已安装匹配版本的游戏及 Node.js。
脚本会优先寻找系统 Node.js，也可使用本机 Codex 自带的 Node.js。

仅上传源码（不构建、不发布 Release）：
powershell -NoProfile -ExecutionPolicy Bypass -File tools\Sync-GitHub.ps1 -SkipRelease

指定游戏目录或原版资源包：
powershell -NoProfile -ExecutionPolicy Bypass -File tools\Sync-GitHub.ps1 -GameDirectory "D:\SteamLibrary\steamapps\common\Solbrand Demo"

仅检查文件和本机构建条件（不登录、不上传）：
powershell -NoProfile -ExecutionPolicy Bypass -File tools\Sync-GitHub.ps1 -CheckOnly

仅校验现有 GitHub 授权（不重新登录、不构建、不上传）：
powershell -NoProfile -ExecutionPolicy Bypass -File tools\Sync-GitHub.ps1 -CheckLogin

本版修复 Windows PowerShell 的 UTF-8 BOM 输入兼容问题。
此前已在网页完成的有效授权可以直接复用，不需要重复授权。

如发现 origin 已指向其他仓库、账号不一致、远端冲突或同名 Release 内容不一致，脚本会停止并说明原因。
